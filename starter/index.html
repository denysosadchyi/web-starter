Common questions

Edit these placeholders for your project. The disclosure widget uses native <details>, no JS required.

  • How do I customize the design?

    Edit assets/css/tokens.css. Every visual value lives there. Change the brand color and font on day 1, the rest cascades.

  • Can I use this with React or Vue?

    Yes. The CSS body is portable. Swap selectors for your scoping mechanism (CSS modules, scoped Vue styles, Tailwind via @apply).

  • Where do I get icons and photos?

    See docs/assets-workflow.md. Lucide for icons via CDN, Imagen / Unsplash for retina photos.
