Зроби аудит поточного стану проекту на anti-slop патерни. Повний список патернів у `docs/anti-slop.md`.

## Що перевірити

Пройдись по `assets/css/components/*.css` і `index.html` (та інших HTML-сторінках, якщо вони є). Для кожного знайденого патерну з нижченаведеного списку запиши:
- де (файл, селектор/секція)
- який саме патерн
- як виправити

### Візуальний шар

- Тонкий акцентний бордер збоку rounded-card (`border-left: 3px solid var(--brand)` або подібне)
- Glassmorphism / `backdrop-filter: blur` як декорація без функціонального сенсу
- Drop-shadowed rounded rectangle як контейнер за замовчуванням для всього
- Sparkline / mini-chart без реальних даних
- Icon-tile стек над заголовком (іконка-в-плашці поверх H3 у feature-картці)
- Картка всередині картки (nested cards)

### Колір

- Purple/violet або cyan-on-dark градієнти
- Gradient text на заголовках
- Glowing colored box-shadow на dark-bg
- Pure `#000` background (мусить бути ink-tinted, не pure black)
- Сірий текст на кольоровому фоні (washed out, низький контраст)

### Типографіка

- Тільки одна family для всього (без display-pair)
- Inter / Roboto / Geist / Plus Jakarta / Space Grotesk як єдиний шрифт без контрасту
- All-caps body (uppercase допустимий тільки для labels)
- Body нижче 14px
- Line-height нижче 1.3 на body
- Letter-spacing вище 0.02em на body
- Лінія тексту довша 80 символів без `max-width: 65-75ch`

### Layout

- Центрований text у всіх блоках (центруй тільки hero і CTA)
- Hero "великий метрик + 3 supporting stats"
- Сітка 3-4 ідентичних карток
- Один spacing скрізь (нема ритму tight-within / large-between)

### Motion

- Bounce / elastic easing
- Анімація `width / height / padding / margin` (мусить бути `transform / opacity / grid-template-rows`)

### Інтеракція

- Кожна кнопка стилізована як primary
- Заголовки повторюють один-одного: kicker → H2 → перший рядок body — однакова думка тричі

### Адаптив

- `display: none` для критичних фіч на мобайлі (адаптуй, не ховай)

## Як вивести результат

```
## Аудит anti-slop

### Знайдено: N патернів

1. **<файл>:<селектор>** — <патерн коротко>
   Як виправити: <одне речення>

2. ...

### Чисто

- <коротко що ОК і чому>
```

Без оцінок "це красиво". Або патерн є, або нема. Якщо в коді нема жодного патерну, скажи це прямо.

## Якщо знаходиш слоп

Не виправляй автоматично. Покажи список, дай користувачу вирішити що чинити. Деякі патерни можуть бути свідомим вибором (наприклад, dark mode як частина бренду).
