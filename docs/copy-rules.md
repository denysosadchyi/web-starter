# Правила копірайту

Як писати тексти, щоб сайт не звучав так, наче його написав ChatGPT за 30 секунд.

## Мікро-маркери AI у тексті

Це слова і конструкції, які моделі видають за замовчуванням. Перепиши або викинь.

### Em-dash (—)

**Найпомітніший AI-маркер.** Моделі обожнюють em-dash як універсальний роздільник.

```
Погано:  "Це найкращий вибір — простий, швидкий і зрозумілий — для будь-якого проекту."
Добре:   "Це найкращий вибір. Простий, швидкий, зрозумілий. Для будь-якого проекту."
```

Заміняй em-dash на:
- крапку
- кому (якщо це список)
- двокрапку (якщо далі пояснення)
- дужки (якщо це додаток до основної думки)

В UA-копірайті це особливо важливо. Em-dash в українському тексті виглядає ще більш штучно, ніж у англійському.

### Конструкція "не просто X — це Y"

```
Погано:  "Це не просто платформа — це твій новий спосіб тренуватись."
Добре:   "Це платформа для тренувань без підписки."
```

Шаблон "це не просто X, це Y" видає AI на лонч-сторінці. Видали все що до коми, лиши конкретику.

### "Ваше" / "Ваш" / "Ви" з великої

Якщо це не офіційний документ, не пиши "Ви" з великої. У вебі це вибиває з тону. Лиши "ви" / "ти" з малої або переписуй у безособово.

```
Погано:  "Ми створили цей продукт спеціально для Вас."
Добре:   "Створено для тих, хто тренується без зала."
```

### AI-favored phrases (англ.)

Список слів і фраз, які моделі видають за замовчуванням. Якщо знаходиш — переписуй.

- "leverage" → "use"
- "elevate" → cut
- "unleash" → cut, "release", "open up"
- "in today's fast-paced world" → cut completely
- "dive deep into" → "look at", "study"
- "seamlessly" → "smoothly", "without friction", або cut
- "robust" → "solid", "reliable", або cut
- "cutting-edge" → cut
- "game-changing" → cut, або конкретно "saves 4 hours/week"
- "unlock" → "give", "open"
- "harness the power of" → cut completely
- "delve into" → "look at"
- "navigate" (як дієслово, переносно) → "find your way", "deal with"
- "bespoke" → "custom" (тільки якщо реально custom)
- "ecosystem" (метафорично) → cut

Якщо хоч одна фраза з цього списку є в тексті — текст звучить як ChatGPT. Перепиши.

### UA-favored AI-фрази

- "у сучасному світі" → cut
- "в епоху цифровізації" → cut
- "новий рівень" → конкретно ЯКИЙ рівень
- "інноваційний" → який саме
- "унікальний підхід" → опиши підхід без слова "унікальний"
- "відкрийте для себе" → cut, починай з конкретики
- "наша місія" → cut, починай з того що ви робите
- "ми дбаємо про" → cut, описуй ЯК ви дбаєте

## Структурні правила

### Один заголовок не повторює інший

```
Погано:
  Kicker:    Простий і швидкий старт
  H2:        Почни швидко й просто
  Subhead:   Прості кроки, щоб почати швидко

Добре:
  Kicker:    Як це працює
  H2:        Три кроки до першого тренування
  Subhead:   Реєстрація, вибір, оплата. Тренування за пів години.
```

Kicker задає категорію. H2 несе value-prop. Subhead додає конкретику. Кожен елемент мусить **додати щось нове**.

### Кожен текст заробляє своє місце

Якщо параграф можна викинути, і сторінка не стане гірша — викинь.

```
Погано:
  H2: Наші переваги
  P:  В нашому продукті є багато переваг. Ось основні з них:
  [список переваг]

Добре:
  H2: Чому це працює
  [список переваг]
```

Вступний параграф "ось список" зайвий. Заголовок і список самі за себе.

### Конкретика > абстракція

```
Погано:  "Швидко, просто, надійно."
Добре:   "Бронювання за 30 секунд. Без реєстрації. Гроші повертаються, якщо тренер не зʼявився."
```

Цифри, факти, конкретні дії. Прикметники без обʼєкту нічого не значать.

### Не пиши те, що очевидно з UI

```
Погано:  Над input-ом: "Введіть свою email-адресу нижче в поле, щоб підписатись"
Добре:   Над input-ом: "Email"  (placeholder: "you@email.com")
```

Якщо є input — користувач знає що туди можна писати. Не пояснюй.

## Тон

### Знайди голос на одному реченні

Перш ніж писати все, напиши одне ключове речення в тоні бренду. Воно стає еталоном.

Приклади голосів:

- **Серйозний / професійний**: "Track your runs with precision sensors and adaptive AI coaching."
- **Дружній / casual**: "Track your runs. Get smarter coaching. Don't overthink it."
- **Жорсткий / рекламний**: "Faster. Smarter. Yours."

Кожен підхід ОК. Що не ОК — змішувати їх на одній сторінці. Hero у "casual" + footer у "професійний" виглядає рваним.

### Уникай pronoun-spam

```
Погано:  "Ми створили продукт. Ми зробили його простим. Ми вірили що це важливо."
Добре:   "Створено простим. Тому що складність вбиває звичку."
```

"Ми / нас / наш" у кожному реченні читається як корпоративна сторінка з 90-х. Або говори безособово, або від другої особи ("ти отримуєш"), або фокусуй на продукті.

### Без exclamation marks

Окликів не повинно бути. Або одне на всю сторінку, або жодного. Виняток — error-меседжі ("Сталася помилка!" — і то можна без знаку).

```
Погано:  "Це чудово! Реєструйся зараз! Не пропусти!"
Добре:   "Реєстрація. Без оплати, без емейл-розсилок."
```

## Конкретні форми

### CTA-кнопки

```
Погано:  "Click here", "Дізнатись більше", "Натисніть тут"
Добре:   "Знайти тренера", "Забронювати сесію", "Подивитись як це працює"
```

Дієслово + конкретна дія. Користувач має одразу зрозуміти, що станеться після кліку.

### Form labels

```
Погано:  "Будь ласка, введіть вашу електронну поштову адресу"
Добре:   "Email"
```

Коротко. Placeholder для прикладу формату ("you@email.com"). Helper-text знизу для технічних деталей ("Не надсилаємо розсилок").

### Error messages

```
Погано:  "Введено неправильні дані"
Добре:   "Email не схожий на email. Перевір що є @ і крапка."
```

Конкретно ЩО не так і ЯК виправити. Не "невалідно" — а що саме невалідно.

### Empty states

```
Погано:  "Тут поки нічого нема"
Добре:   "Немає бронювань на цьому тижні. Знайти заняття →"
```

Empty state це шанс. Покажи що робити далі.

## Чекліст перед шипом

- [ ] Жодного em-dash (—) у тексті
- [ ] Жодних "leverage / unleash / dive deep / seamlessly"
- [ ] Жодних "у сучасному світі / інноваційний / унікальний"
- [ ] Один тон голосу від hero до footer (без миксу casual + corporate)
- [ ] Кожен параграф додає щось нове (не повторює заголовок)
- [ ] CTA-кнопки = дієслово + конкретика
- [ ] Помилки кажуть ЩО і ЯК виправити, не просто "невалідно"
- [ ] Empty states пропонують наступну дію
- [ ] Не "Ви" з великої (якщо це не юр-документ)
- [ ] Один окличний знак на всю сторінку (або жодного)
